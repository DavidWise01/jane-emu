# AV-276R — Generational memory
Rust ledger with private sealed generations, monotonic sequence/frame checks, bounded capacity (64 generations, 1024 receipts each), separate actor tags and read-only inherited counts. Live adapter records interval counts of guarded primitive returns, not individual controller receipts, and discards intervals crossing observed actor changes. Attribution remains provisional. Seals at 32 or more rows per generation. Session-only WASM memory; no reload persistence, survival learning, or cross-session transfer claimed. Scope change or frame rewind stops ingestion.
