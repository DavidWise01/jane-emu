## Hegemonic / diodic operating contract

1. A single authorized controller owns input at any instant.
2. Choose the highest priority **eligible** safe action, with fixed deterministic tie-break; do not build a voting layer.
3. Keep a one-way, append-only event record. Never rewrite earlier test results.
4. Preserve browser playability over decoration, training complexity or consensus.
5. Separate actual runtime evidence from synthetic/stubbed tests and source inspection.

## Hard stop / transition trigger

The **first requirement** for independent witness adjudication, triple-witness voting, Byzantine fault tolerance, distributed authority, leader elections or competing-controller consensus **closes Phase 2 immediately**. Freeze version, evidence, remaining risks, and earned percentage; promote the topic to Phase 3. Do not spend additional Phase 2 turns implementing that machinery.

This is an architectural scope rule, not a claim that real environments can ignore safety or uncertainty.
