## AV-186 — Three-tool consolidation (2026-11-22)

**UI design:** exactly three top-level instrument groups, while keeping the NES game iframe and cartridge/volume/speed/START/life-loss controls visible above the stage:

- **PLAY:** controls, game-facing synchronization, live gamepad and practical play tools.
- **LEARN:** observation training, adaptive policy, neural and background learning instruments.
- **VERIFY:** AV-175–185 evidence modules, startup telemetry, recovery records and test/export panels.

`dashboard/av186_three_tools.js` reorganizes the existing instrument DOM nodes rather than cloning or deleting them. Their IDs, event listeners, game state and inline NES controller remain in place. Newly inserted direct instruments route to one of the three groups. Tabs are a presentation selection, **not separate game controllers**.

`tests/av186_three_tools.test.cjs` checks the three categories, core tool routing, and preservation of the iframe, ROM selector, START control and handoff pathway.
