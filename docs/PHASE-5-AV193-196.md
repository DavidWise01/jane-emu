## AV-193 · Original NES controller cartridge

To avoid a dependency on copyrighted commercial ROMs and expose the actual gameplay path, AV-193 ships an **original in-browser generated NROM-128 iNES cartridge** in `dashboard/av193_test_rom.js`. The new **PLAY TEST ROM** button appears in the existing game toolbar, without adding a fourth tool or new emulator.

### Cartridge controls

- **START**: set the game's started state and enable its sprite rendering
- **Directional pad**: move a visible 8×8 sprite
- **A**: change the sprite to a red palette color
- **B**: change the sprite to an alternate green palette color
- **SELECT**: recenter the sprite

The cartridge uses actual 6502 instructions and memory-mapped NES input register `$4016`, PPU palette, sprite RAM and frame timing. It has a 16 KiB program, 8 KiB character ROM and an iNES header. All bytes are generated in the current browser; there is no external ROM download, injected game substitute, or fake frame clock.

**PLAY TEST ROM** dispatches the resulting .nes file through the original `load(file)` handler. The existing emulator core, action policy, speed, sound, player handoff and three tools remain intact.

### Test levels and honesty

`tests/av193_controller_rom.test.cjs` checks deterministic ROM construction and emulates the required 6502 instructions in a minimal test harness, asserting that START enables sprite output, movement changes NES coordinates and A/B/SELECT alter the intended game variables. That establishes construction and basic program logic, **not** actual jsnes compatibility or visible browser gameplay. CI must pass without promoting live acceptance.

### Human browser acceptance

1. Open [Jane's live arcade](https://davidwise01.github.io/jane-emu/), choose **PLAY TEST ROM**, and watch the original emulator screen.
2. Confirm that the game displays a player sprite after START, that directional inputs move it, and A and B produce distinct sprite color changes. If Jane is on autoplay, observe the completed actions; use the original cabinet controls if needed.
3. Export the existing AV-185 and AV-189/AV-188 evidence under VERIFY if the run succeeded or failed; keep actual visually observed behavior distinct from instrumentation.

**Current evidence:** No real jsnes browser session has been verified. **Phase 5 credit remains 0%.**

## AV-193 headless emulator execution result

The first deterministic 6502 harness passed, and the subsequent **actual JSNES 2.1.0 headless emulator test passed** in [GitHub Actions run 45070505487](https://github.com/DavidWise01/jane-emu/actions/runs/45070505487). The emulator accepted the original NROM cartridge, START changed its internal game mode, RIGHT/DOWN moved the sprite coordinates, A/B produced distinct palette values, and SELECT recentered the player. This test runs the actual JSNES CPU/PPU/controller machinery, rather than only a custom instruction interpreter.

**Remaining gap:** Neither GitHub Actions nor headless JSNES prove the currently deployed arcade's visible browser canvas, autoplay timing, or end-to-end button response. Phase 5 therefore remains **0% browser-verified** until a real session confirms those behaviors. The three-tool layout is unchanged.

## AV-194 · Rendered NES sprite and action evidence (2026-11-22)

AV-194 extends the genuine JSNES core test from zero-page memory into **NES PPU pixels**. The test `tests/av194_jsnes_framebuffer.test.cjs` records real `onFrame` 256×240 framebuffers and asserts:
- Before START, no active sprite occupies the player region; after START, a localized 8×8 region changes on-screen.
- A RIGHT command increases the player's on-screen horizontal sprite bounding-box position, not only its RAM coordinate.
- A DOWN command increases the vertical bounding-box position.
- A and B each produce changes in actual rendered sprite pixel colors.
- Frame counts advance, and all checks operate against the same original AV-193 NROM program in JSNES 2.1.0.

**Result:** The new framebuffer test passed in [GitHub Actions run 45072131630](https://github.com/DavidWise01/jane-emu/actions/runs/45072131630). The original NES game and the three top-level Play / Learn / Verify tools remain intact; no fourth panel was introduced.

**Scope of proof:** genuine JSNES PPU pixel rendering with emulator controller inputs, but not the hosted GitHub Pages browser/iframe, nor autonomous gameplay improvement. Phase 5 remains **0% end-to-end browser verified**, with this stronger headless evidence explicitly tracked.

**Next natural bound — AV-195:** run an end-to-end browser/iframe test of PLAY TEST ROM, click START and actuate D-pad and A/B through the actual arcade controls. Diagnose and repair input delivery, sprite visibility or handoff failures before claiming gameplay.

## AV-196 — Visible arcade sprite and controlled Phase 5 freeze (2026-11-22)

**Successful actual Chromium browser evidence:** [GitHub Actions 45084123984](https://github.com/DavidWise01/jane-emu/actions/runs/45084123984). Its new `tests/av196_canvas_rotation_browser.test.cjs` loads the original AV-193 NROM test cartridge through **PLAY TEST ROM**, uses the production START action, and reads the pixels from the embedded emulator's real 256×240 `nesCanvas`. START visibly renders an 8×8, 64-pixel sprite (bounding box X 120–127 / Y 115–122).

Without reloading the NES, the browser's **manual, operator-confirmed** life-loss button transfers ownership from Jane to Toph at frame **253**, to Patricia at frame **382**, and back to Jane at frame **512**. All transfers retain the same game root, cartridge and advancing NES frame clock. The three top-level tools remain PLAY, LEARN and VERIFY. Browser page errors: none.

**Critical limits discovered and preserved:**
- Pressing directional keyboard keys during Chromium testing interrupted frame advancement. The actual user keyboard/focus route needs repair and has **not** passed.
- Bounded automated gameplay actions provided RIGHT and DOWN effects during a diagnostic run, but A/B were not reliably scheduled after the movement actions. Further tests of the player's production controller-port input and action scheduler failed.
- The local-only test input fixtures used to investigate those failures have been **fully removed** from production `dashboard/arena.html`. No second emulator, additional control panel, or test override remains in the arcade.
- Manual controller handoff is not an objectively measured NES life loss. Frame continuity over 512 frames is not a long-running endurance certificate.

The intended AV-195 real movement/A/B and genuine-defeat criteria, and the AV-196 endurance graduation criterion, remain unearned.
