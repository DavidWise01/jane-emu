# AV-238/239 — Neon Storm monitoring

Implements previously proposed lightning effects in actual arcade HTML. Narrow decorative zigzag arcs on existing monitoring instruments, active tab color cyan/magenta/amber, smooth four-to-five-second glow cycle, reduced-motion static fallback. No full-screen flashes, no overlays on the NES viewport, no controller or telemetry changes. All existing HTML outside appended CSS retained. Phase 11 turn 3/8 development; browser verification pending.
